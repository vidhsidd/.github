## ScanPulse

ScanPulse issues ID credentials as signed QR codes. A scanner checks a credential on the spot without an internet connection, and an administrator can revoke it from one place.

- White-label, so it carries your brand
- Built for sites with poor connectivity
- Badge printing and bulk import
- **Status:** a new version is in development. We are looking for a few organisations to run an early pilot.
